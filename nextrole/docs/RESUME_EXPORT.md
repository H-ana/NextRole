# Resume tailoring and PDF export

Confirmed clarification answers, including short fragments, first become proposed complete accomplishment sentences using Gemini and a factual audit. Only selected sentences are inserted into the download draft; raw fragments and ambiguous or rejected suggestions are not added. The answer flow uses one subsequent tailoring batch to retain the five-request review cap. They remain visible if a later AI request fails. AI wording, summary and ordering suggestions still require selection; rejected or unchanged suggestions never become edits. Reviews use the current download draft, while the original retained resume remains the source for job matching. Unconfirmed typed answers cause a clear prompt rather than being silently discarded. A review asks at most two missing-evidence questions.

The one-page PDF is generated locally using bundled jsPDF and embedded Carlito regular/bold fonts (a standard-width Calibri-compatible alternative). It never uses browser printing, so browser URL/date/page-number headers and footers are absent. Text remains selectable. Bullet markers, numbering, indentation and hanging wraps are preserved from the draft. Repeated empty lines collapse to compact spacing. Layout tries 11, 10.5 and 10 pt body text on A4 with half-inch margins. If the complete approved content cannot fit at 10 pt, export stops without deleting content or shrinking text further.

DOCX imports use Mammoth's list-aware HTML instead of raw text. For an older retained Word resume, the editor can recover list structure from its locally saved original file only when text remains identical after ignoring whitespace and list markers. This formatting recovery never alters the matching resume or overwrites changed draft wording. It is skipped if the saved file cannot be verified against the retained source.

These are document and content checks, not employer ATS certification. Font or library loading failures, unsupported characters and overflow produce an error rather than an incomplete file. The original Word export remains available in Calibri. Libraries and fonts are served with the app; applicant text is not uploaded for PDF generation. jsPDF uses the included MIT license; Carlito uses the included SIL OFL license; Mammoth uses its included license.

Verification: synthetic short, dense and blank-line-heavy resumes are generated and rendered; page count and extracted text are compared with the complete approved source. Browser checks cover confirmed/unconfirmed answers, simulated provider failure, list import and local PDF/font loading. No live Google request or applicant document is used in these automated fixtures.

Clarification wording checks use explicit spelling/spacing proposals (Langraph/Lang Graph → LangGraph; Fast API → FastAPI), case-insensitive name matching, duplicate-fact merging and optional bullet punctuation. The raw answer stays visible alongside the proposed sentence. A separate factual audit and explicit wording/technology-name approval remain required. Rejected answers show a specific reason and remain visible. Other wording checks retain the stricter edit validator.

Clarification contribution and negation paraphrases are judged by the mandatory semantic audit rather than an exact protected-word bag. Hard guards still reject changed numbers, invented tools, new leadership claims and new seniority/proficiency claims. Pronouns and common narrative verbs are not named-tool anchors. Team attribution, uncertainty and undocumented frameworks must retain their meaning. Rejected candidate wording is displayed for inspection and is never saved.
